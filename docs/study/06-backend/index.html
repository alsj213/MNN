概览

MNN 通过 Backend 抽象层支持 CPU (ARM NEON/RISC-V/x86)、GPU (OpenCL/Vulkan/Metal)、NPU (CoreML/NNAPI/QNN) 多种硬件后端。同一模型在不同后端执行，通过 Backend::onCreate 工厂实现多态。

面试重点

MNN 如何支持多后端？
通过 Backend 抽象层。每个后端实现 Backend 的子类（CPUBackend / OpenCLBackend / MetalBackend），重写 onCreate (Op 工厂) / onAcquireBuffer (内存) / onCopyBuffer (拷贝) / onSync (同步)。上层 Pipeline 不关心具体后端。
DIRECT vs INDIRECT 执行模式？
DIRECT（CPU）：onExecute 直接算完返回。INDIRECT（GPU）：onExecute 只录制 kernel launch，onExecuteEnd 批量提交+等待。INDIRECT 减少 CPU-GPU 同步开销，多个 kernel 可批量提交。
跨后端数据传输怎么处理？
Pipeline::allocMemory._InsertCopy 检测 Tensor 生产者和消费者的 Backend 是否相同。不同则插入 Copy Command，通过 onCopyBuffer(Backend::onCopyBuffer) 做中转（通常经过 CPU host memory）。
INDIRECT 模式为什么只在 GPU 用？
GPU kernel launch 有延迟，批量提交（batching）可分摊开销。CPU 计算即算即得，无 command buffer 概念。Metal / OpenCL / Vulkan 都支持 command buffer / command queue 模型。
