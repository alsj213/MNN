概览

Transformer Block 架构

输入 [batch, seq_len, dim]
  │
  ├─ Attention Block:
  │    ├─ linear QKV ──→ Q, K, V [batch, head, seq, dim_head]
  │    ├─ RoPE(Q), RoPE(K)                     (位置编码)
  │    ├─ KVCache: concat past + current       (自回归推理)
  │    ├─ Q @ K^T / sqrt(d) → Softmax → × V    (Scaled Dot-Product Attention)
  │    └─ linear Output
  │
  ├─ Add & LayerNorm  (残差连接)
  │
  ├─ FFN Block:
  │    ├─ linear↑ (gate + up) → SiLU
  │    └─ linear↓
  │
  └─ Add & LayerNorm

面试重点

MNN 中如何新增一个 Op？
四步：① MNN.fbs 定义 OpType + OpParameter ② source/shape/ 注册 SizeComputer ③ source/backend/cpu/ 注册 CPU Creator（REGISTER_CPU_OP_CREATOR）④ 实现 Execution onResize + onExecute。
KV Cache 的作用和实现？
自回归推理时，之前 token 的 K/V 已算过不需要重算。KVCache 把历史 K/V 缓存起来，每步只需算新 token 的 QKV、attention 时 concat 历史 K/V。内存随序列长度线性增长。
Prefill vs Decode 两阶段？
Prefill：一次性处理 prompt 的所有 token（并行），建立 KV Cache。Decode：逐 token 自回归生成（串行），每步只算新 token + 更新 KV Cache。
Attention 的 FLOPs 如何计算？
Q@K^T: batch×head×seq²×dim_head；Softmax: batch×head×seq²；×V: batch×head×seq²×dim_head。核心是 O(seq²) 的 QK 矩阵乘，长序列时成为瓶颈。
