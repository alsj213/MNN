三步标准 Attention

Step 1 — Q @ K^T:
  Q [seqLen, headDim] × K^T [headDim, kvLen] → scores [seqLen, kvLen]
  乘以 mScale = 1/√(headDim), 加 mask

Step 2 — Softmax:
  softmax(scores) → probs [seqLen, kvLen]
  在 Flash Attention 模式下在线累积 (无需完整显存)

Step 3 — Softmax @ V:
  probs [seqLen, kvLen] × V [kvLen, headDim] → output [seqLen, headDim]

Step 2: MNNSoftmax (Attention 专用)

// CommonOptFunction.cpp:2890 — 支持 flash attention 在线更新

for each packUnit:
  newMax = max(srcPtr[i])                        // 找块内最大值
  finalMax = max(oldMax, newMax)                 // 在线合并历史最大值

  MNNExp(dstPtr, srcPtr, exprOffset, packUnit)  // exp(x - finalMax)

  if (runningMax != nullptr):                    // Flash Attention 模式
    scaleForSum = exp(oldMax - finalMax)         // 重缩放因子
    runningSum[k] = runningSum[k] * scaleForSum + sum
    runningMax[k] = finalMax
    updateScale[k] = scaleForSum                 // 用于后续输出更新
  else:
    scale = 1.0 / (sum + 1e-20)                  // 最终归一化
    dst[j] *= scale

MNNExp NEON 近似 (exp 快速计算)

// CommonOptFunctionNeon.cpp:407 — 4 阶多项式 + 整数幂技巧

exp(x) = 2^k × exp(r),  k = round(x / ln2),  r = x - k×ln2

1. k = vrndaq_f32(vmulq_f32(x, LN2_INV))      // k = round(x/ln2)
2. r = vfmsq_f32(x, k, LN2)                    // r = x - k*ln2
3. P(r) = C0 + C2×r² + C4×r⁴ + r×(C1 + C3×r²) // 4th-order exp(r) approx
4. 2^k = reinterpret((k+127) << 23)     // 浮点表示的位技巧
5. exp(x) = P(r) × 2^k
