LayerNorm (CPULayerNorm.cpp, 180 行)

公式

RMSNorm:  y = x / sqrt(mean(x²) + ε) × γ      (只归一化方差, 无均值中心化)
LayerNorm: y = (x - μ) / √(σ² + ε) × γ + β    (完整归一化)

MNN 用 MNNNorm 统一实现两种模式 (mRMSNorm 标志)

NEON 均值计算

vaddvq_f32 水平归约 → 最终均值

NEON 归一化 + Scale

// 16 个 float 一批:
v0 = vld1q(&src[j+0])
v0 = vsubq_f32(v0, vmean)          // 中心化: x - μ
v0 = vmulq_f32(v0, vvar)           // 缩放: × 1/√(σ²+ε)
s0 = vmlaq_f32(b0, s0, g0)         // dst = β + normalized × γ (FMA)

// 4 条 NEON 指令完成 4 个元素的完整 LayerNorm
// 其中 FMA 融合了 ·γ + +β 两步

RMSNorm vs LayerNorm 性能

RMSNorm: 省去均值计算 → ~30% 少算
  只需要: sum(x²) → 1/√(sum/N+ε) → x × variable × γ
  LLM 多用 RMSNorm (LLaMA/Qwen/DeepSeek)

LayerNorm: 需要均值 + 方差
  先算 μ → 再算 σ² → (x-μ)/σ × γ + β

标准 Softmax

// _MNNSoftmax — 单轴 softmax

1. Max:    MNNMaxFloat(src) → NEON vmaxq 归约
2. Exp:    MNNExp(dst, expOffset={0, -Max}) → exp(x - Max)
           同时累加到 expOffset[3] = Σexp(x-Max)
3. Scale:  mulFunction(dst, dst, &sumDiv) → dst /= sum

// expOffset = {0, 1, -Max, 0}
// expOffset[3] 在 MNNExp 内部被更新为 sum

多轴 Softmax

// _softmaxCommon — 对指定轴做 softmax
for 每个 batch:
  1. maxFunction → 沿 axis 找最大值
  2. subFunction → dst = src - max
  3. MNNExp     → dst = exp(dst)
  4. addFunction → 沿 axis 求和
  5. recFunction × mulFunction → dst /= sum

RoPE (旋转位置编码)

MNN 中的 RoPE 不是独立 Op

★ RoPE 是图级构造, 不是融合 kernel!

模型 ONNX 图中:
  position_ids → Sin/Cos → Slice → half1, half2
  Q/K → split → [x1,x2] × cos ± [rotate(x2),rotate(x1)] × sin
  → 用标准 ONNX 算子表达 (Sin, Cos, Mul, Add, Concat, Slice)

MNN 直接执行这些标准 Op, 无需专门 RoPE kernel

rotate_half 技巧 (数学层面)

给定向量 x = [x₀, x₁, ..., x_d₋₁]:
  x_left  = [x₀, x₁, ..., x_{d/2-1}]
  x_right = [x_{d/2}, ..., x_{d-1}]
  rotated_x = [-x_{d/2}, ..., -x_{d-1}, x₀, ..., x_{d/2-1}]

RoPE(dim i):
  cos_i = cos(pos × θ_i),  sin_i = sin(pos × θ_i)
  x'_i = x_i × cos_i + rotated_x_i × sin_i

MNN 图用: Mul/Add 完成上述公式, 无专用汇编
