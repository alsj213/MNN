Diffusion — 扩散模型推理

概览

MNN 支持 Stable Diffusion 1.5 / 2.1 / XL / SD3.5 和 SANA 等扩散模型推理。扩散模型通过迭代去噪生成图像，每个 denoising step 包含 UNet / Text Encoder / VAE 三个子模型。

Diffusion 推理 Pipeline

prompt = "a cat sitting on a couch"

┌─ Text Encoder (只跑一次) ──────────────────┐
│  CLIP Tokenizer → Text Encoder → embedding │
│  输出: 文本条件向量 [1, 77, 768]             │
└────────────────────────────────────────────┘
  │
  ▼
┌─ Denoising Loop (迭代 N 步) ───────────────┐
│  for t in timesteps (1000→0, 通常 20~50 步):│
│    1. 随机噪声 + 当前 latent + t + text_emb │
│    2. UNet 预测噪声                         │
│    3. Scheduler 更新 latent (去噪一步)        │
│  → 输出: 去噪后的 latent [1, 4, H/8, W/8]   │
└────────────────────────────────────────────┘
  │
  ▼
┌─ VAE Decoder (只跑一次) ────────────────────┐
│  latent [1,4,64,64] → VAE Decode            │
│  → 图像 [3, 512, 512]                       │
└────────────────────────────────────────────┘

面试重点

扩散模型推理的瓶颈在哪？
UNet 的多次迭代（20-50 步）是主要瓶颈。每步都需要完整跑一次 UNet 前向，总推理时间 ≈ 单步 UNet 时间 × 步数。优化方向：减少步数（DDIM 采样）、UNet 量化/剪枝、Batch 调度。
UNet 的结构特点？
Encoder-Decoder 对称结构 + Skip Connection。下采样提取特征 → Bottleneck → 上采样恢复分辨率。每个 block 包含 ResBlock + Attention + Time Embedding。和分类 CNN 的 UNet 不同，Diffusion UNet 输入条件包括 timestep 和 text embedding。
VAE 在 Diffusion 中的作用？
编码器 (Encoder) 将图像压缩到 latent space（8× 下采样），解码器 (Decoder) 将 latent 恢复为图像。Diffusion 过程在 latent space 进行（而非像素空间），大幅减少计算量。Latent 通常 4 通道，而原图 3 通道。
Scheduler 的作用？
控制去噪过程的步长和噪声调度。DDPM 按固定 β 序列加噪/去噪；DDIM 允许跳步加速（从 1000 步减少到 20-50 步）；Euler Ancestral 引入随机性增加多样性。Scheduler 决定"每一步去多少噪声"。

学习路径建议

  1. Diffusion 数学原理：前向加噪 → 反向去噪 (DDPM / DDIM)
  2. 导出流程：convert_mnn.py 如何拆分 Text Encoder / UNet / VAE
  3. UNet 推理：ResBlock + SpatialTransformer + CrossAttention
  4. Scheduler：DDIM / Euler 采样步长与去噪更新公式
  5. VAE Decoder：latent → 像素图像的完整数据流
  6. SD3.5 / SANA：MMDiT / DiT 新架构对比
