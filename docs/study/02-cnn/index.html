面试重点

Im2Col + GEMM 的原理？
将卷积的滑动窗口访存转化为矩阵乘法。Im2Col 把每个窗口拉成行向量 [oh×ow, ic×kh×kw]，权重展成 [oc, ic×kh×kw]，做矩阵乘得到 [oh×ow, oc]。FLOPs 不变，但变成规整 GEMM 可利用 BLAS/SIMD 加速。
Winograd 为什么比 Im2Col 快？
Winograd 通过数学变换减少乘法次数。F(2×2, 3×3) 用 16 次乘代替直接卷积的 36 次乘（2.25× 减少），代价是更多的加法。适合 3×3 小核 + stride=1。
深度可分离卷积与普通卷积的区别？
普通卷积：每个输出通道看所有输入通道。Depthwise：每个输出通道只看自己对应的输入通道（group=channel）。计算量从 O(ic×oc×k²) 降为 O(ic×k²)，MobileNet 核心思路。
INT8 量化如何减少计算量？
INT8 乘加比 FP32 快 2-4×（SIMD 一次处理更多元素），内存带宽减半。需要 scale/zero_point 做量化反量化，部分后端有专门 INT8 指令（ARM v8.2 dot product）。
